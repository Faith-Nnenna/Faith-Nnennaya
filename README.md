UPLOAD TO YOUR EXISTING GITHUB REPOSITORY
1. Extract this ZIP first.
2. Open the Faith-Nnenna repository, then Add file > Upload files.
3. Select ALL extracted files together and upload them at the top level, beside the existing index.html. Replace files with the same names. Keep all image and font files beside index.html.
4. Commit directly to main. GitHub Pages will redeploy the website.
5. After the deployment succeeds, hard-refresh the page with Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac).

This package contains the complete website, including images and fonts. You do not need the original ZIP or a separate assets folder. The ZIP itself is not the website: upload its extracted contents.
